2. 분류 체계

2-1. 종류 (무엇에)

식비, 카페/간식, 술/모임, 쇼핑, 교통, 주거, 통신, 구독, 의료, 자기계발, 경조사, 기타

구독 세부 분류: AI(Claude, ChatGPT 등), 영상(OTT), 음악, 클라우드, 게임, 기타

2-2. 필요도 (왜)

표시의미선택
🟢 필수생활에 꼭 필요한 지출직접
🟡 계획미리 생각해둔 선택 지출직접
🟠 허용 충동충동 누적이 월 한도 이하자동 판정
🔴 초과 충동충동 누적이 월 한도 초과, 또는 한 건 상한 초과자동 판정

기록할 때는 🟢 필수 / 🟡 계획 / 🔴 충동 중 하나만 고르고, 🟠/🔴 구분은 앱이 자동으로 계산한다.

2-3. 감정 태그 (선택)

스트레스, 심심함, 기분 좋음, 친구 분위기, 배고픔, 보상심리 (사용자가 편집 가능)

3. 충동 판정 규칙

3-1. 월 충동 용돈

  • 기본 한도: 100,000원/월
  • 이월: 없음 (매달 1일 다시 10만 원)
  • 충동 누적이 한도 이하이면 🟠, 넘는 부분부터 🔴
  • 한 건이 한도를 걸치면 금액을 나눠서 판정
예시 (한도 10만 원)
3일 충동 배달 2만 → 누적 2만 🟠
10일 충동 쇼핑 7만 → 누적 9만 🟠
15일 친구 2차 술 3만 → 1만 🟠 + 2만 🔴
이후 충동은 전부 🔴

3-2. 한 건 상한선

  • 기본 50,000원. 충동 1건이 이 금액 이상이면 한도가 남아 있어도 🔴
  • 설정에서 끌 수 있음

3-3. 주간 페이스

  • 월 한도 ÷ 그달 주 수 = 주간 권장액 (예: 약 2.5만 원)
  • "이번 주 권장 2.5만 중 1.8만 사용"으로 표시. 경고만 하고 막지 않음

3-4. 충동 의심 질문

🟢/🟡로 기록했지만 아래 조건에 해당하면 한 번 되묻는다. 최종 판단은 사용자가 한다.

  • 밤 11시 ~ 새벽 4시 지출
  • 배달 앱, 쇼핑몰 지출
  • 같은 날 같은 종류에 3번 이상 지출
예: "새벽 배달인데 진짜 필수였어? [필수 맞음] [충동으로 바꾸기]"

3-5. 충동 구독 (별도 집계)

  • 필요도가 🔴인 구독은 월 충동 용돈에서 차감하지 않음
  • 대신 "충동 구독 월 ○원"을 별도 지표로 표시
  • 구독 재검토 알림으로 관리 (4-6 참고)

3-6. 남은 충동 용돈 = 참은 돈

  • 월말에 충동 한도 − 충동 지출을 "참은 돈"으로 기록 (생활비가 아니라 충동 용돈 기준)
  • 이월은 안 하지만 누적 기록을 보여줌: "올해 참은 돈 누적 186,000원"
  • 저축 목표 진행률에 반영 가능

4. 기능 요구사항

4-1. 지출 기록

  • 입력 항목: 금액, 날짜, 종류, 필요도, 결제수단, 메모(선택), 감정 태그(선택)
  • 3초 입력: 금액 → 종류 아이콘 → 필요도 탭 → 저장
  • 즐겨찾기 템플릿: "점심 / 9,000 / 신한체크 / 🟢"를 원탭으로 기록
  • 지난 날짜 입력: 기본값 오늘, [어제] [그저께] [날짜 선택] 버튼
  • 수정/삭제 가능

4-2. 하루 마감 (무지출 vs 미기록 구분)

  • 기록을 입력했거나 [오늘 무지출]을 누르면 그날은 ✅ 마감
  • 마감 안 된 날은 달력에 ⚠️ 표시
  • 다음 날 "어제 기록 안 했어요" 알림

4-3. 결제수단

  • 등록 항목: 이름(예: 현대 신용카드), 종류(현금/체크/신용/계좌이체/간편결제), 신용카드는 결제일과 사용 기간
  • 신용카드별 이번 달 사용액 + 다음 결제일 예정 출금액 표시

4-4. 할부 관리

  • 등록: 항목명, 총액, 개월 수, 시작 월, 카드
  • 매달 할부금이 자동으로 잡힘
  • "남은 할부 4회 / 80만 원" 표시. 신용카드 예정 출금액에 포함

4-5. 고정 지출

  • 항목, 금액, 출금일, 주기(매월/매년/매주), 결제수단, 필요도
  • 예: 월세, 통신비, 보험, 적금, 대출 이자
  • 날짜가 되면 자동 기록. 금액이 바뀌는 항목(전기세 등)은 확인 요청

4-6. 구독 관리

항목예시
이름 / 요금제Claude / Max
세부 분류AI
금액, 결제일, 카드매달 ○일, 현대카드
필요도🟢 / 🟡 / 🔴
상태사용중 / 해지 예정 / 해지됨
시작일 / 해지일
변경 이력2026-09 Pro 🟢 → 2026-11 Max 업그레이드 🔴
  • 구독 재검토 알림: 시작 후 1개월, 3개월마다 "아직 필요해? [유지] [다운그레이드] [해지]"
  • 무료 체험 종료 알림: "3일 후 유료 전환돼요"
  • 구독 총액 표시: "구독료 매달 67,000원, 1년이면 80만 원"

4-7. 예산

  • 월 전체 예산, 종류별 예산
  • 오늘 쓸 수 있는 돈 = (월 예산 − 고정 지출 − 지금까지 쓴 돈) ÷ 남은 일수

4-8. 목표

종류예시
지출 한도월 예산 / 충동 한도
종류별술/모임 월 10만 원 이하
행동배달 주 2회 이하, 무지출 날 월 4일, 새벽 결제 0회
감소충동 지출 지난달 대비 20% 감소
저축여행 자금 300만 원, 2027년 6월까지 (참은 돈과 연결)

처음에는 행동 목표 1~2개 + 저축 목표 1개만 사용하는 것을 권장.

4-9. 충동 금액 환산

  • 물건 단위: 사용자가 단위 등록 (커피 4,500 / 치킨 23,000 / 제주도 왕복 120,000) → "이번 달 충동 = 치킨 6마리"
  • 목표 단위: "초과 충동 4.2만 = 여행 자금 목표의 1.4%, 달성 5일 늦어짐"
  • 1년 예상치: "지금 페이스면 1년 충동 170만 원"
  • 노동 시간 (선택): 시급 입력 시 "이번 달 충동 = 11.8시간 일한 돈"
  • 표시 위치: 충동 기록 직후 한 줄, 월말 리포트, 위젯(선택)

4-10. 돌아보기

  • 후회 리뷰: 충동/계획 지출 일주일 후 "만족했어? 👍/👎" → 후회율 높은 소비 분석
  • 사고 싶은 것 목록: 등록하고 48시간 후 "아직도 사고 싶어?"
  • 무지출 챌린지, 연속 기록, 배지
  • 키우는 화분: 목표를 지키면 자라고, 초과하면 시듦. 위젯에도 표시

4-11. AI 월간 소비 코치

  • 월말에 그달 데이터 요약을 Claude API로 보내 코칭 문장 생성
  • 개인정보 최소화: 금액, 종류, 필요도, 요일/시간대 같은 집계값 위주로 전송
예: "이번 달 충동 지출의 60%가 금요일 밤 술자리였어요. 금요일 2차를 한 번만 줄이면 한도 안에 들어와요."

4-12. 카드 내역 엑셀 업로드 (웹)

  • 카드사 이용내역 엑셀/CSV 업로드
  • 규칙 자동 분류 ("스타벅스 → 카페")
  • 이미 기록한 거래와 중복 감지 (같은 금액 + 비슷한 시간)
  • 용도: 한 달에 한 번 빠진 거래 찾기

4-13. Google 캘린더 연동

A. 앱 → 캘린더 (지출 표시)

  • 앱 전용 "가계부" 캘린더를 만들어 거기에만 기록 (기존 일정과 분리, 켜고 끄기 가능)
  • 하루 요약 (종일 일정): "💸 52,000원 · 🔴 18,000", 설명에 상세 내역 + 남은 충동 용돈
  • 제목 이모지로 그날 상태 표시: 충동 없음 🟢 / 허용 충동 🟠 / 초과 충동 🔴
  • 미래 일정: 고정 지출(D-3 알림), 구독(D-1), 신용카드 출금 예정액(D-3, 사용액에 따라 자동 업데이트), 할부 회차

B. 캘린더 → 앱 (일정 분석)

  • 약속 있는 날 vs 없는 날 평균 지출 비교
  • 특정 일정(예: 동기 모임)과 충동 지출의 관계
  • 전날 알림: "내일 친구 모임 일정이 있어요. 남은 충동 용돈 3.2만 원"
  • 지출 기록에 그날 일정 자동 연결. 일정은 제목과 시간만 사용

기술: Google OAuth + Google Calendar API. 하루 요약은 서버 예약 작업으로 작성.

5. 플랫폼별 기능

5-1. 웹 (PC · 분석, 관리, 계획)

  • 대시보드: 월별 지출 추이, 종류별 비율, 필수/계획/충동 비율의 월별 변화
  • 달력 히트맵 (지출 많을수록 진하게, 마감 안 된 날 ⚠️)
  • 충동 리포트: 요일별, 시간대별, 감정별, 충동 Top 5, 전월 대비
  • 카드 내역 엑셀 업로드, 여러 건 일괄 수정
  • 고정 지출, 구독, 할부, 카드, 목표 관리 화면
  • 월간 리포트 + AI 코치
  • 설정 (카테고리, 감정 태그, 예산, 한도, 환산 단위, 분류 규칙)

5-2. 폰 (PWA → 안드로이드 앱 · 빠른 기록)

  • 3초 입력, 즐겨찾기 템플릿
  • 오늘 쓸 수 있는 돈, 충동 게이지, 주간 페이스
  • 하루 마감, 각종 알림
  • 오프라인 입력 후 동기화

5-3. 폰 위젯 (3단계 · 안드로이드 앱 필요)

PWA로는 위젯을 만들 수 없어서 안드로이드 앱 단계에서 결제 알림 인식과 함께 구현한다.

크기내용
작은 (2x1)오늘 남은 돈
중간 (4x2)오늘 남은 돈, 충동 게이지(🟢→🟡→🔴), 주간 페이스, [+ 빠른 기록]
큰 (4x4)위 내용 + 종류별 막대 그래프 + 다음 고정 지출 D-day

5-4. PC 바탕화면 위젯

방법단계설명
PWA 미니 창1단계설치된 웹 창을 작게 띄움
항상 위 미니 창1단계크롬 Document PiP로 그래프 창을 항상 맨 위에
진짜 데스크톱 위젯3.5단계Tauri로 웹 코드를 재사용해 바탕화면 위젯 제작

표시 내용: 일별 지출 미니 그래프, 필수/계획/충동 도넛, 충동 게이지 + 주간 페이스, 다가오는 고정 지출/구독, 마감 안 된 날 ⚠️, 화분

5-5. 결제 알림 자동 인식 (3단계 · 안드로이드만)

  1. 카드사 앱 결제 푸시(또는 문자) 알림 켜기
  2. 내 앱에 안드로이드 "알림 접근 권한" 허용
  3. NotificationListenerService로 카드사 앱 알림만 골라 정규식으로 카드, 금액, 가게, 시간 추출
  4. "분류 대기"로 저장 → 내 앱 알림에서 [🟢] [🟡] [🔴] 탭으로 기록 완료
  5. 취소 알림이 오면 자동 취소, 직접 입력한 건과 중복 확인
아이폰은 다른 앱의 알림을 읽을 수 없어서 불가능. 혼자 쓸 때는 APK를 직접 설치하면 돼서 플레이스토어 심사가 필요 없음.

MVP (PWA)

  • 카드 등록 (신용카드 결제일, 예정 출금액)

  • 월 예산, 오늘 쓸 수 있는 돈
  • 충동 판정 (월 10만, 한 건 5만)
  • 하루 마감 (무지출 / 미기록)
  • 웹 기본 대시보드
  • PC 미니 창 / 항상 위 창
